# TikTok Marketing API GraphQL API

TikTok Marketing API covers campaign management, ad groups, creatives, audiences, targeting options, pixel events, attribution, and reporting for TikTok advertising.

**Endpoint:** NONE. TikTok publishes no GraphQL API. This file and the accompanying
`tiktok-ads-schema.graphql` are an API Evangelist *conceptual* rendering of the REST
Marketing API as a GraphQL schema — a modelling exercise, not a TikTok surface. Verified
again on 2026-08-13: no /graphql endpoint exists on business-api.tiktok.com and the docs
name none. No `type: GraphQL` pointer is wired in apis.yml, deliberately, so this is never
read as a GraphQL API TikTok ships.
**Documentation:** https://business-api.tiktok.com/portal/docs
