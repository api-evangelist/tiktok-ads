# TikTok Marketing API GraphQL API

TikTok Marketing API covers campaign management, ad groups, creatives, audiences, targeting options, pixel events, attribution, and reporting for TikTok advertising.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from TikTok Marketing API REST API
**Documentation:** https://business-api.tiktok.com/portal/docs
