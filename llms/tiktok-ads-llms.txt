# TikTok Marketing API (TikTok API for Business)

> TikTok for Business is TikTok's advertising platform. The TikTok API for Business —
> Marketing API — is a REST API at business-api.tiktok.com/open_api/v1.3 for managing
> advertiser accounts, campaigns, ad groups, ads, creatives, catalogs, audiences,
> Business Centers, conversion measurement and reporting. TikTok also operates a hosted
> Model Context Protocol server that packages roughly 400 of these endpoints as MCP tools.

Generated by the API Evangelist enrichment pipeline on 2026-08-13. TikTok publishes no
llms.txt of its own — /llms.txt returns 404 on business-api.tiktok.com, ads.tiktok.com
and developers.tiktok.com.

Three things dominate correct use of this API:
- HTTP status is not the error channel. Almost every response is HTTP 200; success is
  `code == 0` inside the JSON body. A client that checks `response.ok` reads every error
  as a success.
- There is no idempotency key. No write on this API is safe to blind-retry.
- Every endpoint path ends in a trailing slash, and the slash is required.

## APIs
- [TikTok Marketing API v1.3](https://business-api.tiktok.com/portal/docs): REST API, base https://business-api.tiktok.com/open_api/v1.3
- [Sandbox environment](https://business-api.tiktok.com/portal/docs?id=1738855331457026): base https://sandbox-ads.tiktok.com/open_api/v1.3, 21 supported endpoints
- [TikTok for Business MCP Server](https://business-api.tiktok.com/portal/docs/tiktok-ads-mcp-server/v1.3): remote MCP, OAuth, ~400 tools

## MCP endpoints
- https://business-api.tiktok.com/open_mcp/tt-ads-mcp-flat — full disclosure, ~400 tools at connect
- https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer — progressive disclosure, ~40 core tools
- Auth: OAuth 2.1 authorization code + PKCE, scope `mcp:tt4b`, dynamic client registration, 30-day grant
- No developer app or API key required for MCP
